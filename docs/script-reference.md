# Script reference

Generated by `baker::reference()` from what a Context registers. Do not edit it by
hand: the test suite regenerates it and fails when it and the code disagree.

A parameter in [brackets] is optional, `unevaluated` is passed as written, and
`values...` takes the rest of the arguments.

## Functions

### `!`

- `{! bool}` → bool

*Native.* As `not`: `{! $a}`.

### `!=`

- `{!= value value values...}` → bool

*Native.* Inequality of every adjacent pair.

### `%`

- `{% int int}` → int

*Native.* Remainder of int division, with the sign of the dividend.

### `&&`

- `{&& values...}` → bool

*Native.* As `and`, for infix: `{$a && $b}`.

### `*`

- `{* number number number...}` → value

*Native.* Product: `{* 2 3 4}`, or infix `{2 * 3 * 4}`.

### `*=`

- `{*= $variable number}` → value

*Native.* `{$x *= n}`: multiplies the place and returns the new value.

### `+`

- `{+ number number number...}` → value

*Native.* Sum: `{+ 1 2 3}`, or infix `{1 + 2 + 3}`.

### `+=`

- `{+= $variable number}` → value

*Native.* `{$x += n}` or, in a method, `{[property] += n}`: adds to the place and returns the new value.

### `-`

- `{- number number...}` → value

*Native.* Difference, left to right: `{10 - 2 - 3}` is 5; with one argument, negation.

### `-=`

- `{-= $variable number}` → value

*Native.* `{$x -= n}`: subtracts from the place and returns the new value.

### `/`

- `{/ number number number...}` → value

*Native.* Quotient, left to right, always a float.

### `/=`

- `{/= $variable number}` → value

*Native.* `{$x /= n}`: divides the place, always to a float, and returns the new value.

### `<`

- `{< number number number...}` → bool

*Native.* Less than: `{< 1 2}`, or chained, `{1 < $x < 10}`.

### `<=`

- `{<= number number number...}` → bool

*Native.* Less than or equal: `{0.3 <= $value <= 0.7}` is a band.

### `==`

- `{== value value values...}` → bool

*Native.* Equality: numbers by value (1 equals 1.0), anything else by structure; chained, every adjacent pair.

### `>`

- `{> number number number...}` → bool

*Native.* Greater than.

### `>=`

- `{>= number number number...}` → bool

*Native.* Greater than or equal.

### `and`

- `{and values...}` → bool

*Native.* True if every argument is; stops at the first false one.

### `class`

- `{class values...}` → value

*Native.* `{class Name (method ($params...) body...) ...}`: script handlers. If `Name` is a bound C++ type, they apply to its objects and are tried before its C++ methods; otherwise `Name` is a script class for `new`. In a handler, `$this` is the object and `[name]` its property or parameter.

### `delete`

- `{delete value}` → value

*Native.* `{delete object}`: removes the object (or the object of that name) when the host's eval returns, or at the end of a tick; one `new` created is destroyed. Its handles go stale.

### `do`

- `{do values...}` → value

*Native.* `{do ($a ($b 1)) body...}`: binds the variables (unset, or to a value) for the duration of the body, restores them after, and returns the body's last value. Without the list, just runs the body.

### `extend`

- `{extend values...}` → value

*Native.* `{extend Name (method ($params...) body...) ...}`: adds script handlers to a class, replacing only those of the same name, so another file (a task pack) can add one. `Name` is a `{class}` or a bound C++ type. Run it after the `{class}`: a redefinition replaces every handler.

### `func`

- `{func values...}` → value

*Native.* `{func name ($params...) body...}`: defines a script function. `(status stub)`, `(status provisional)`, `(status deprecated replacement)` and `(doc "...")` may follow the parameters.

### `if`

- `{if bool unevaluated [unevaluated]}` → value

*Native.* `{if cond then [else]}`: evaluates `then` if `cond` is true, else `else` if given (else 0). Only the branch taken is evaluated.

### `new`

- `{new values...}` → value

*Native.* `{new Class [name] (param value)...}`: creates an object of a script class or of a default-constructible bound type, owned by the Context, and returns it.

### `not`

- `{not bool}` → bool

*Native.* Negation.

### `or`

- `{or values...}` → bool

*Native.* True if any argument is; stops at the first true one.

### `override`

- `{override values...}` → value

*Native.* As `func`, but may replace a native function, which it logs.

### `set`

- `{set $variable value}` → value

*Native.* `{set $var value}` or, in a method, `{set [property] value}`: stores the value and returns it.

### `wait`

- `{wait values...}` → value

*Native.* Suspends a `{scheduler thread_task ...}`; only as one of its commands.

### `wait_for`

- `{wait_for values...}` → value

*Native.* Suspends a `{scheduler thread_task ...}`; only as one of its commands.

### `wait_tick`

- `{wait_tick values...}` → value

*Native.* Suspends a `{scheduler thread_task ...}`; only as one of its commands.

### `||`

- `{|| values...}` → bool

*Native.* As `or`, for infix: `{$a || $b}`.

## Types

Every object also has `{obj get name}`, `{obj set name value}`, `{obj type}` and `{obj name}`.

### `Scheduler`

- `{<Scheduler> cancel int}` → nothing: `{scheduler cancel handle}`: ends a task a *_task command returned.
- `{<Scheduler> delay_task float values...}` → value: `{scheduler delay_task t body...}`: runs `body` once, `t` units from now.
- `{<Scheduler> interp_task $variable float float values...}` → value: `{scheduler interp_task $var from to body...}`: steps `$var` from `from` to `to` over |to - from| units, running `body` each tick, the last time at exactly `to`.
- `{<Scheduler> now}` → float: `{scheduler now}`: the Scheduler's time.
- `{<Scheduler> thread_task values...}` → value: `{scheduler thread_task cmd...}`: runs its commands in order across ticks. `{wait cond}`, `{wait_for t}`, and `{wait_tick}` suspend it, as its own commands.
